# 知乎文章：丝路十故事

**标题：** 我在丝路知识图谱上复原了十个人的旅程，结果发现了一个历史最残酷的规律

---

做了两个月的丝绸之路交互知识图谱，现在做到了第十个交互故事。

十个故事。十个人。十段改变世界的旅程。

做完之后回头看，发现了一个我最初完全没想到的规律——**历史书写的权力，从来不属于"普通人"。**

## 十个人，十种出发

**张骞**（公元前138年）：汉武帝派出去的。带着帝国使命，持节出使，凿空西域。出发时身后是一个王朝的意志。被匈奴扣了十年，逃出来继续走。

**班超**（公元73年）：36个人进西域。31年后，西域五十余国全部归附。投笔从戎的抄书员，成了定远侯。官方史书为他立传，千古名句「不入虎穴不得虎子」出自他口。

**法显**（399年）：60岁出发。没有皇帝派遣，没有军队护送。五个人结伴，回来时只剩他一个。在斯里兰卡佛殿里看到一柄晋朝的白绢扇，泪流满面——离家十一年，同伴全死了。

**玄奘**（629年）：偷渡出境的。唐朝禁止出境，他混在灾民中溜出长安。但他出发前已经是名僧，印度之旅让他成为整个东亚佛教界最权威的人物。唐太宗亲自出城迎接。

**杜环**（751年）：一个随军文人。名字都没在正史里单独出现过。怛罗斯之战唐军大败，几千人被俘，他是其中之一。**前四个和后四个都是主动出发的。杜环不是。他是被阿拉伯军队押着离开战场的。**

**丘处机**（1219年）：全真教长春真人，七十三岁。金朝请不去，宋朝请不去。但成吉思汗的使臣从蒙古赶来，带着虎头金牌——他去了。带着十八个弟子，从山东莱州出发，走了三年、两万里，穿越蒙古高原和西域，最终在阿富汗兴都库什山见到了成吉思汗。大汗问「有何长生之药」，他答「有卫生之道，而无长生之药」。四次论道，核心只有四个字：敬天爱民。史称「一言止杀」。弟子李志常著《长春真人西游记》，与《大唐西域记》并列丝路经典。**一个道士，面对世界上最有权势的杀戮者，反复说：停下来。**

**马可·波罗**（1271年）：威尼斯富商之子。带着教宗回信和圣油去见忽必烈汗。在元朝当了十七年"公务员"，回到威尼斯后口述了一本改变世界地图的书。哥伦布出海时船舱里就放着它。

**拉班·扫马**（约1275年）：元大都的景教修士。五十多岁带着弟子出发去耶路撒冷朝圣。命运的意外把他推上了蒙古大汗使节的位置——1287年，他成了唯一一个从北京走到巴黎的中国人。拜占庭皇帝、法王腓力四世、英王爱德华一世依次接见了他。他的游记用叙利亚文保存下来，但中文世界几乎没人知道他。

**汪大渊**（1330年）：二十岁从泉州搭商船出海。比郑和早75年。走到印度、阿拉伯、东非。写了一本《岛夷志略》，完整的。但他不是官方使节，只是"搭船的"——所以正史里一笔带过。

**郑和**（1405年）：大明帝国的舰队司令。两百艘船，两万七千人，七下西洋。永乐皇帝最信任的人之一。随从写了三种书，全部完整保存。

## 同样的路，不同的命运

十个人走过了丝路。但他们的故事被保存下来的方式，天差地别：

| 人物 | 身份 | 原著保存 |
|------|------|---------|
| 张骞 | 帝国使节 | 《史记·大宛列传》完整 |
| 班超 | 定远侯·西域都护 | 《后汉书·班梁列传》完整 |
| 法显 | 名僧 | 《佛国记》完整保存 |
| 玄奘 | 大唐高僧 | 《大唐西域记》完整保存 |
| 郑和 | 帝国将军 | 随从著书三种完整保存 |
| 马可·波罗 | 富商之子 | 《行纪》完整保存 |
| 汪大渊 | 民间航海家 | 《岛夷志略》完整但冷门 |
| 拉班·扫马 | 景教修士 | 游记叙利亚文保存，中文世界失传 |
| **杜环** | **战俘** | **只剩1511字** |
| 丘处机 | 道教宗师 | 《长春真人西游记》完整保存 |

规律一目了然：**社会地位越高，你的故事越容易被完整保存。地位越低，越容易被遗忘。**

但拉班·扫马是个例外——他的地位不低，他是蒙古大汗的正式大使。他的游记也完整保存了。但因为他写的是叙利亚文，保存在中东的修道院里，所以中国人几乎不知道他。**语言和地理的壁垒，也可以让一个人从自己民族的历史中消失。**

## 一个战俘的十一年

回到杜环。

他被俘后没有被杀。阿拉伯人需要工匠和识字的人。他被编入后勤队伍，随军穿越了整个阿拔斯王朝。

他走的路放到今天看：

**撒马尔罕** — 被俘的唐朝造纸工匠正在开作坊。造纸术就是这样传入伊斯兰世界的。杜环记下了他们的名字：「画者，京兆人樊淑、刘泚；织络者，河东人乐怀、吕礼。」——他没有漏掉任何一个同胞。

**巴格达** — 八世纪全世界最伟大的城市。他记录了阿拉伯人的饮食、服饰、婚丧、市场。

**大马士革** — 中国最早的伊斯兰教田野调查，准确到令人惊叹：「大食法者，不食猪狗驴马等肉，不拜国王父母之尊，不信鬼神，唯拜天。一日五时礼天。」

**非洲** — 他到达了一个叫"摩邻国"的地方。第一位留下非洲文字记录的中国人。

**麦加** — 看到了天房（Kaaba），记录了朝觐仪式。比郑和的随从马欢早了六百年。

十一年后（762年），他从波斯湾搭上阿拉伯商船，经印度洋、马六甲、南海，回到广州。

他写了一本书——《经行记》。

原书在宋代以后失传。我们今天能读到的，只有杜佑《通典》中引用的1511个字。

**一千五百字，十一年。**

## 我为什么还在做这件事

我做这套丝路交互知识图谱的初衷很简单——让历史可探索，而不是可背诵。

现在已经做了十个人：张骞、班超、法显、玄奘、杜环、丘处机、马可·波罗、拉班·扫马、汪大渊、郑和。十个人的旅程，每一个都有7个章节。打开网页，地图会自动飞越到每一个关键地点，弹出叙事卡片。路线是**累计绘制**的——你不会看到断续的线段，你看到的是一个人如何一步步走完整条路。

从汉到明。从长安到巴黎。从太平洋到印度洋。

但做完十个故事回头看，我觉得更重要的是：**用技术给每一个走过这条路的人一个容器。** 张骞值得被看见，班超值得，法显值得，杜环也值得——哪怕他的书只剩一千五百字。丘处机也值得——哪怕他是一个道士而不是商人或高僧。拉班·扫马也值得——哪怕他的名字对中国人来说完全陌生。
