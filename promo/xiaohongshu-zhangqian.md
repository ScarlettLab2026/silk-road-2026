## 配文（小红书 caption · ≤1000字 ✅ 约540字）

公元前139年，汉武帝做了一个决定：派一个人穿过匈奴的地盘，去找西方的大月氏结盟。

这几乎是一个送死的任务。接任务的人叫张骞。

他带着一百多人出了陇西，刚过黄河，匈奴骑兵就到了。军臣单于把他扣在草原上，给他娶了匈奴妻子，想把他同化。但张骞做了一件事——他一直保留着那根代表汉朝使节的节杖。「持汉节不失」。

十年。他在草原上住了整整十年，才趁乱逃脱。

但他没有回头向东。他选择继续往西走。

🌏 后面的事，司马迁在《史记》里用两个字评价：「凿空」。

张骞穿过了塔克拉玛干沙漠边缘，翻越了帕米尔高原的冰峰——这是中国人第一次用自己的脚步丈量通往西方的路。他到了大宛（费尔干纳）、康居、大月氏。大月氏已经在阿姆河流域安居乐业，不想打仗了。但张骞在西域走了一年多，把沿途各国的地理、物产、风俗——记在心里。

回程又走南道，结果再次被俘。一年后趁乱逃回长安。

从出发到归来，整整十三年。出发时百余人，回来时只剩他和堂邑父两人。

🏇 他带回了什么？大宛汗血宝马的情报、西域各国的路线图、苜蓿的种子、葡萄的栽法、胡桃和石榴的来历。丝绸之路的第一张「地图」，是他用十三年走出来的。

张骞之后，班超再定西域，玄奘沿着他开辟的路西行取经，粟特商人在这条路上接力贸易千年。从长安到罗马——第一个人，是他。

## 🎨 张骞 · 凿空西域 · 视觉设定

> 张骞是丝路知识图谱的第一篇——他是「第一个走通这条路的人」。视觉上应该在「汉代美学+大漠史诗+竹简/节杖符号」之间找到平衡。

### 核心视觉元素

**主色调：** 大漠沙 → 汉铜金 → 竹简褐 → 雪山灰白
- background: `#faf6ed`（丝路沙白）
- accent gold: `#b8860b`（汉铜金）
- accent desert: `#c4956a`（大漠赭）
- accent oasis: `#4a7c5c`（绿洲绿）
- accent snow: `#dce4e8`（葱岭灰白）
- text dark: `#2c2016`（墨褐）
- text light: `#8b7355`（浅褐）

**关键符号：**
- 🏜️ 沙漠 + 沙丘纹理
- 🏇 汗血宝马（Akhal-Teke 的金属光泽）
- 🪶 汉节（竹竿 + 三层牦牛尾饰）
- 📜 竹简 / 地图
- 🍇 葡萄、苜蓿、胡桃、石榴（带回来的物种）
- 汉阙 / 汉画像石纹样

**区别于其他故事：**
- 不是药铺/书斋的静态场景 → 是沙漠、草原、雪山的壮阔户外
- 不是知识传播者/求法僧 → 是开拓者、探险家、国家使节
- 沙白底色（不是李珣的乳白药铺色）
- 汉铜金为主色（不是波斯蓝），传递汉代古朴质感
- 「节杖」是贯穿所有卡片的超级符号

### ⚠️ 生图避坑指南

| 不要 | 要 |
|------|-----|
| 唐代风格的建筑/服饰 | 西汉风格——曲裾深衣、汉阙、未央宫 |
| 明清式城墙/城门 | 汉式夯土城墙+阙楼 |

| 光滑的丝绸质感背景 | 沙漠纹理、竹简肌理、粗麻质感 |
| 过度华丽的宫廷场景 | 汉代古朴克制的美学——不是大唐的绚烂 |
